# Narrative Taxonomy

Choose one value only when it clearly describes the paper's dominant evidence progression:

| Value | Typical progression |
|---|---|
| `Phenomenon-to-Mechanism` | Phenomenon → Perturbation → Mechanism → Model |
| `Screen-to-Mechanism` | Screen → Hit → Validation → Mechanism |
| `Association-to-Causality` | Association → Perturbation → Causality → Mechanism |
| `Perturbation-to-Mechanism` | Perturbation → Phenotype → Mechanism → Rescue |
| `Dynamics-to-Driver` | Dynamics → Pattern → Driver → Function |
| `Structure-to-Function` | Structure → Perturbation → Function → Mechanism |
| `Disease-to-Mechanism` | Disease/Phenotype → Gene/Variant → Mechanism → Pathology |
| `Atlas-to-Discovery` | Atlas → Classification → Pattern → Discovery |
| `Method-to-Discovery` | Method → Benchmark → Application → Discovery |
| `Prediction-to-Validation` | Model → Prediction → Experiment → Discovery |

Write only the value, without a `#narrative/` prefix. Leave `narrative:` empty for mixed or unclear structures.
